# Modelo de e-mail para Fornecedores

Ao aderir a nova ferramenta, é recomendado que informe os fornecedores para que possam se adequar a ferramenta também. Segue abaixo um esqueleto de e-mail que pode ser enviado aos seus fornecedores.
_____
<br><br><br><br><br>


### Prezado (a), boa tarde!

Solicitamos especial apoio aos nossos fornecedores quanto as observações contidas em nossos Pedidos de Compra, pois é de extrema importância para estabelecer conformidade com as nossas especificações.

Nesta mensagem em especial, queremos tratar sobre os campos no arquivo XML das NFes: "<span style="color:red">**XPed**</span>" e "<span style="color:red">**nItemPed**</span>". Esses campos correspondem ao número do pedido e o item do pedido.

Esclarecemos que temos uma melhoria para importação automática dos arquivos XML's com o objetivo de eliminar erros com a digitação e ainda aumentar a produtividade no processo de recebimento das mercadorias.

Estes campos deverão ser preenchidos conforme o exemplo abaixo:

- XPed: 079358
- nItemPed: 0001
Lembramos que já é uma observação destaque em nossos pedidos de compra, mas infelizmente alguns fornecedores não estão atendendo. Peço agilizar os ajustes necessários para que até o dia 31/12/2023 todos os arquivos XML já tenham a informação correta.

IMPORTANTE: Informamos que a partir do dia 01/01/2023, não será possível o recebimento de mercadorias com "XML" sem o preenchimento correto dos campos em questão. 



- Para os fornecedores obrigados a emissão de Nota Fiscal Eletrônica, a NF só será aceita e registrada com envio do arquivo XML para nfe@com.br (Conforme AJUSTE SINIEF 07/05, § 7º);

- É OBRIGATÓRIO CONSTAR NA NFe O NÚMERO DESTE PEDIDO (Tags: xPed e nItemPed)

Atenciosamente.
